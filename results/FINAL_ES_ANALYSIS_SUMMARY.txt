   - Median angle: 136.0°

================================================================================
KEY FINDINGS
================================================================================

1. FILTERING HELPS BUT NOT ENOUGH:
   ✓ Removing CC clusters improved resolution by 23°
   ✗ Still pointing systematically backward (median 113° vs ideal 0°)

2. MCMC PROVIDES NO BENEFIT:
   - Pure energy-weighted average: 112.9°
   - MCMC optimization: 113.3° (0.4° worse!)
   - Conclusion: The problem is not the combination method

3. ROOT CAUSE IDENTIFIED:
   - The ED model predicts ELECTRON directions (outgoing particles)
   - In ES scattering: electron scatters at an angle to the neutrino
   - In CC interactions: electron goes roughly forward relative to neutrino
   - The ED model doesn't know it should predict NEUTRINO direction

4. PHYSICS EXPLANATION:
   - ES (elastic scattering): ν + e⁻ → ν + e⁻
     * Electron scatters, carries partial energy/momentum
     * Scattering angle depends on energy transfer
   - The ED model learned electron trajectories from training data
   - These trajectories point in various directions relative to neutrino
   - No simple "flip" fixes this - it's event-by-event kinematics

================================================================================
RECOMMENDATIONS
================================================================================

1. RETRAIN ED MODEL:
   - Train to predict NEUTRINO direction instead of ELECTRON direction
   - Use neutrino_px/py/pz from ROOT files as labels (constant per category)
   - This requires retraining from scratch

2. ALTERNATIVE: KINEMATIC CORRECTION:
   - Use electron energy + direction to infer neutrino direction
   - Apply ES scattering kinematics: cosθ_ν = f(E_e, θ_e)
   - Would require single-electron-track selection (not multi-cluster)

3. CURRENT APPROACH LIMITATIONS:
   - Multi-cluster averaging loses single-electron kinematic information
   - Energy-weighted average assumes all clusters point similarly
   - This assumption is invalid when electron scatters

4. SHORT-TERM OPTION:
   - Test manual flip (-direction) to see if resolution improves to ~45°
   - This would indicate model learned consistent electron direction
   - But this is physically incorrect and won't work for all events

================================================================================
CONCLUSION
================================================================================

The analysis successfully identified that:
  1. ES cluster filtering is ESSENTIAL (23° improvement)
  2. MCMC optimization is NOT helpful (0.4° worse)
  3. The ED model architecture/training needs revision
  4. Current median resolution: 113° (pointing mostly backward)
  5. Best achievable with current model + flip: ~45° (estimated)

To achieve good pointing (<20° resolution), the ED model must be retrained
to predict neutrino direction, not electron direction.
