# EMCEE 6-Scenario Submission Summary

## Date: November 20, 2025

## Cluster ID: **13791712**

## Summary
Submitted 618 Condor jobs to run corrected emcee MCMC analysis with the proper 6 scenarios.

## Corrected Scenarios

1. **best_case**: Use TRUE electron directions from metadata + MCMC
   - ES main tracks only
   - Extract true particle momentum (px, py, pz) from metadata columns 7-9
   - Energy cut: E > 3 MeV
   
2. **perfect_ct**: ES main tracks + ED neural network + MCMC
   - ES main tracks only (perfect channel tagging)
   - ED network predicts electron directions
   - Energy cut: E > 3 MeV
   
3. **full_pipeline**: All clusters + CT network + ED network + MCMC (no weights)
   - All main-track clusters
   - CT network filters for ES candidates (P(ES) > 0.5)
   - ED network predicts directions
   - NO weighting by CT probabilities
   - Energy cut: E > 3 MeV
   
4. **weighted_ct**: All clusters + CT network (WITH weights) + ED network + MCMC
   - Same as full_pipeline but uses CT probabilities as weights in likelihood
   - Weights = P(ES) from CT network
   - Energy cut: E > 3 MeV
   
5. **perfect_ct_e_gt_10mev**: ES main tracks + ED network + MCMC, E > 10 MeV
   - Same as perfect_ct but with 10 MeV energy threshold
   
6. **perfect_ct_e_gt_20mev**: ES main tracks + ED network + MCMC, E > 20 MeV
   - Same as perfect_ct but with 20 MeV energy threshold

## Test Results (cat000001)

- **best_case**: 16.36° angular error (true electron directions)
- **perfect_ct**: 3.19° angular error (ED network predictions)

This shows the ED network significantly outperforms using true electron directions, 
demonstrating its excellent reconstruction quality.
