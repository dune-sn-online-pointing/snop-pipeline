EMCEE vs CURRENT MCMC IMPLEMENTATION - COMPARISON SUMMARY
================================================================================

Date: November 20, 2025
Test case: cat000062, perfect_ct scenario (284 clusters)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
KEY DIFFERENCES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CURRENT METHOD (Cartesian MCMC):
  • Single-chain Metropolis-Hastings
  • Cartesian coordinates (x, y, z) with normalization
  • No prior (uniform sampling issue on sphere)
  • Exponential damping: σ goes from 0.10 → 0.039
  • 50 trials × 10,000 steps, best trial selected
  • Acceptance rate: ~25.6%
  
EMCEE METHOD (Ensemble Sampler):
  • Multiple walkers (ensemble sampling)
  • Spherical coordinates (θ, φ)
  • sin(φ) prior for uniform sphere sampling ✅
  • Fixed proposal scale: σ = 0.1
  • 32 walkers × 1,000 steps
  • Custom boundary wrapping for θ, φ
  • Circular statistics for angular uncertainties

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
TEST RESULTS (LIMITED - USED RANDOM CLUSTER DATA)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WARNING: Test used randomly generated cluster directions biased toward true 
direction (real cluster data not stored in pipeline results).

Current method:  15.52° angular error
Emcee method:    12.74° angular error
Improvement:     2.79° (18% better)

BUT: Emcee had poor convergence metrics:
  • Acceptance fraction: 3.0% (too low, should be 20-50%)
  • Large uncertainties: Δθ=70°, Δφ=26° 
  • 68% credible angle: 137°

This suggests the random test data doesn't represent real distribution properly.

THEORETICAL ADVANTAGES OF EMCEE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ✅ sin(φ) PRIOR
   - Ensures uniform sampling on sphere surface
   - Current method has subtle bias toward poles

2. ✅ ENSEMBLE SAMPLING
   - Multiple walkers explore in parallel
   - More robust to local minima
   - Better convergence diagnosis (can see all walkers)

3. ✅ PROPER UNCERTAINTY QUANTIFICATION
   - Circular statistics for angular parameters
   - 68% credible intervals
   - Full posterior distribution

4. ✅ NATURAL PARAMETERIZATION
   - (θ, φ) directly interpretable as direction
   - Boundary handling explicit

5. ✅ ADAPTIVE PROPOSALS
   - Emcee can use affine-invariant stretch moves
   - Self-tunes to posterior shape

DISADVANTAGES / CONCERNS

1. ⚠️  MORE COMPLEX CODE
   - Requires emcee library
   - More parameters to tune (nwalkers, proposal scale)

2. ⚠️  COMPUTATIONAL COST
   - 32 walkers × 1,000 steps = 32,000 evaluations
   - Current: 50 trials × 10,000 steps = 500,000 evaluations
   - But emcee may converge faster (fewer steps needed)

3. ⚠️  CURRENT METHOD ALREADY WORKS WELL
   - 15.52° is good performance
   - Convergence is adequate (std < 0.01)

4. ⚠️  WOULD NEED TO REPROCESS ALL DATA
   - 150+ cats already processed
   - Results may not be directly comparable
